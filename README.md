# MCP Bridge for Arena

1. edge://extensions -> Режим разработчика -> «Загрузить распакованное» -> эта папка (где лежит manifest.json).
2. Запустите свой MCP-сервер по SSE, например http://localhost:3000/sse
3. Откройте arena.ai, в поле чата наберите:  /c http://localhost:3000/sse   и Enter
   (можно и /c npx -y mcp-remote http://localhost:3000/sse --transport sse-only - расширение возьмёт из неё только URL;
   npx оно запустить не может, и не нужно: оно само говорит с сервером по SSE).
4. Инструкции для модели вставятся в поле чата - отправьте их. Когда модель ответит блоком <function_calls>,
   в панели MCP (правый нижний угол) появится карточка -> «Выполнить» -> результат вставится в поле чата.
